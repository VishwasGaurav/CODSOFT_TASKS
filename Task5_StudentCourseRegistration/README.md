# Task 5 - Student Course Registration System

## Description

This is a Java-based Student Course Registration System developed as part of my CodeSoft Internship.

The system allows students to view available courses, register for courses, view their registered courses, and drop courses.

## Features

- Add student details
- Store course information
- Display available courses
- Show available course slots
- Register for courses
- Drop registered courses
- View student details
- Prevent duplicate course registration
- Check course capacity

## Course Information

Each course contains:

- Course Code
- Course Title
- Course Description
- Course Capacity
- Course Schedule
- Available Slots

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
- Conditional Statements
- Loops

## How to Run

### Compile the program

```bash
javac StudentCourseRegistration.java
