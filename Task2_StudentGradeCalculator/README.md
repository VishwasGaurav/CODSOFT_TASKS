# Task 2 - Student Grade Calculator

## Description

This project is a Java-based Student Grade Calculator developed as part of my CodeSoft Internship.

The program calculates the total marks, average percentage, and grade of a student based on the marks entered for each subject.

## Features

- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average percentage
- Assigns grades based on average percentage
- Validates marks between 0 and 100
- Displays the final result clearly

## Grade Criteria

| Average Percentage | Grade |
|--------------------|-------|
| 90 - 100           | A+    |
| 80 - 89             | A     |
| 70 - 79             | B     |
| 60 - 69             | C     |
| 50 - 59             | D     |
| Below 50            | F     |

## Technologies Used

- Java
- Scanner Class
- Conditional Statements
- Loops

## How to Run

Compile the program:

```bash
javac StudentGradeCalculator.java
