# Task 1 - Number Guessing Game

## Description

This is a Java-based Number Guessing Game developed as part of my CodeSoft Internship.

The program generates a random number between 1 and 100. The player has a limited number of attempts to guess the correct number.

## Features

- Generates a random number between 1 and 100
- Gives the player 7 attempts
- Provides hints:
  - Too High
  - Too Low
- Displays the correct number if the player fails
- Keeps track of the score
- Allows the player to play multiple rounds

## Technologies Used

- Java
- Random Class
- Scanner Class

## How to Run

Compile the program:

```bash
javac NumberGame.java
