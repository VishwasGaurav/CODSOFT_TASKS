# Task 3 - ATM Interface

## Description

This is a Java-based ATM Interface developed as part of my CodeSoft Internship.

The program allows users to securely access an ATM using a PIN and perform basic banking operations.

## Features

- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Insufficient balance checking
- Invalid amount validation
- Exit option

## Technologies Used

- Java
- Scanner Class
- Conditional Statements
- Switch Statement
- Loops

## Default PIN

1234

## Initial Balance

Rs. 10000

## How to Run

Compile the program:

```bash
javac ATMInterface.java
