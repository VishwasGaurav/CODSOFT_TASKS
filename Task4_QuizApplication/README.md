# Task 4 - Quiz Application

## Description

This is a Java-based Quiz Application developed as part of my CodeSoft Internship.

The program asks multiple-choice questions and checks the user's answers. At the end, it displays the total score, correct answers, wrong answers, percentage, and performance.

## Features

- Multiple-choice questions
- Four options for each question
- Automatic answer checking
- Score calculation
- Percentage calculation
- Performance evaluation
- Final result display

## Technologies Used

- Java
- Scanner Class
- Arrays
- Loops
- Conditional Statements

## How to Run

Compile the program:

```bash
javac QuizApplication.java
